# UI Coding Standards

## Component Library: shadcn/ui Only

This project uses **shadcn/ui** as its sole UI component library. All UI elements must come from shadcn/ui. **No custom components may be created.**

## Rules

1. **Use only shadcn/ui components.** Every button, input, dialog, card, table, form element, and layout primitive must be a shadcn/ui component installed via the CLI.
2. **Do not create custom components.** Do not build bespoke UI components in `src/components/`. The only files in `src/components/ui/` should be those generated by `npx shadcn@latest add <component>`.
3. **Do not wrap shadcn/ui components in custom abstractions.** Use them directly. Do not create wrapper components, HOCs, or factory functions around shadcn/ui primitives.
4. **Do not install alternative UI libraries.** No Material UI, Chakra UI, Ant Design, Headless UI, Radix primitives (outside of what shadcn/ui already vendors), or any other component library.

## Adding Components

Install components using the shadcn CLI:

```bash
npx shadcn@latest add <component>
```

Examples:

```bash
npx shadcn@latest add button
npx shadcn@latest add card
npx shadcn@latest add dialog
npx shadcn@latest add input
npx shadcn@latest add table
```

## Styling

- Use **Tailwind CSS utility classes** for layout, spacing, and any additional styling.
- Use the **shadcn/ui theming system** (CSS variables defined in `globals.css`) for colors and design tokens.
- Use the `cn()` utility from `@/lib/utils` to conditionally merge class names.

## Date Formatting

All date formatting must use the **date-fns** library. Do not use `Intl.DateTimeFormat`, `toLocaleDateString()`, or manual string concatenation for dates.

Dates must be displayed in the following format: **ordinal day + abbreviated month + full year**.

| Example Output |
| -------------- |
| 1st Sep 2025   |
| 2nd Aug 2025   |
| 3rd Jan 2026   |
| 4th Jun 2024   |

Use the date-fns `format` function with the pattern `do MMM yyyy`:

```ts
import { format } from "date-fns";

format(new Date(2025, 8, 1), "do MMM yyyy"); // "1st Sep 2025"
```

This format must be used consistently everywhere a date is rendered in the UI.

## Composing Pages

Pages and route-level components in `src/app/` should compose UI entirely from shadcn/ui components and Tailwind classes. If a needed UI pattern does not exist in shadcn/ui, check the shadcn/ui documentation for a supported approach before requesting an exception.
